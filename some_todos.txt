## 1. File Browser & Shell QoL Features (High Priority)

### Core File Operations & Actions
- [ ] **Tab Context Menu:**
  - [ ] Implement right-click context menu on tab headers.
  - [ ] Actions: `Close Tab`, `Close Other Tabs`, `Close Tabs to the Right`, `Duplicate Tab`, `Pin Tab`.
- [ ] **File Manipulation Commands:**
  - [ ] **New File Creation:** Prompt for filename/template in target directory.
  - [ ] **Clipboard Operations:** Implement standard `Cut`, `Copy`, `Paste` (with support for native OS mime-types/clipboards via Avalonia `IClipboard`).
  - [ ] **Delete:** Move to OS Trash/Recycle Bin by default, with `Shift + Delete` for permanent deletion.

---

## 2. Advanced & Power-User Tools

### Cross-Platform Configuration / "RegEdit" Visualizer
- [ ] **Unified Config Engine:**
  - [ ] **Windows:** Native Windows Registry provider via `Microsoft.Win32.Registry`.
  - [ ] **Linux (Virtual Registry Abstraction):** Build a unified tree view interface that presents system/user configuration files as a hierarchical registry structure:
    - [ ] `HKCU` equivalent mapped to `~/.config/`, `~/.local/share/`, and `dconf`/`gsettings`.
    - [ ] `HKLM` equivalent mapped to `/etc/` system configuration files and `/var/lib/`.
    - [ ] Parsers for `.ini`, `.json`, `.yaml`, Keyfile (`/etc/fstab`, `/etc/environment`), and binary dconf databases.
- [ ] **Registry Editor UI (`RegEdit` style):**
  - [ ] Dual-pane view: TreeView navigation on the left, key-value data grid on the right.
  - [ ] Value editors for String, DWORD/Int, Binary, and Multi-String types.
  - [ ] Search, bookmarking, and export/import functionality.
